📊 Project Overview

The DMART Sales Analysis Dashboard is an interactive Excel-based business intelligence solution designed to analyze sales performance, profitability, customer behavior, and regional business trends.

This dashboard transforms raw sales data into meaningful insights through dynamic visualizations, KPI cards, and interactive filters, enabling users to monitor business performance and make data-driven decisions.

🚀 How to Use
Download or clone this repository.
Open DMART_Sales_Analysis.xlsx using Microsoft Excel.
Navigate to the dashboard worksheet.
Use the interactive slicers to filter data by region and customer type.
Explore the charts and KPIs to understand sales and profitability trends.
Navigate to the Raw Data and Pivot Tables sections for additional analysis.
